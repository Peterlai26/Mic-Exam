## ธีม
มี 3 ธีม เลือกได้จากปุ่ม "ธีม" มุมบนขวา (ทั้งหน้าหลักและหน้าชุดเตรียมสอบ) ค่าที่เลือกเก็บใน `localStorage` ของเบราว์เซอร์
- **โปสเตอร์การ์ด** (ค่าเริ่มต้น) · **สมุดแล็บ** · **เรียบง่าย**
- เข้าเว็บครั้งแรกจะมีหน้าเลือกธีมที่ต้องแตะดูให้ครบทั้ง 3 ธีมก่อนเริ่มใช้งาน
- ธีมทั้งหมดนิยามอยู่ในออบเจกต์ `SKINS` ใน `index.html` ส่วนหน้าชุดเตรียมสอบ (iframe) รับ CSS ชุดเดียวกันตอนเปิด
